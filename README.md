# Canelo Architect AI

Standalone parametric architecture studio for modern houses and poultry structures.

## V1
- Modern house and fowl-run modes
- Editable dimensions
- 2D parametric floor plan
- Synchronized interactive 3D model
- Fowl-run capacity sizing
- Project area and density calculations
- Responsive professional workspace

Run with `npm install && npm run dev`.

Concept designs require appropriate local architectural/engineering review before construction.
